# Илья Гажиенко

Frontend-разработчик с опытом более 3 лет.

Разрабатываю интерфейсы и клиентские приложения на React и TypeScript. Работаю с REST API, управлением состоянием, визуализацией данных, тестированием и fullstack-интеграциями.

## Основной стек

React, TypeScript, JavaScript, Redux Toolkit, Zustand, Next.js, HTML, CSS, Sass, Tailwind CSS, REST API, Git, Vite и Webpack.

Тестирование: Vitest, Jest, Testing Library и Playwright.

## Избранные проекты

### PDF Recipes Store

Приватный коммерческий сервис продажи PDF-рецептов с оплатой через YooKassa, email-уведомлениями и защищённой выдачей файлов. Публичный showcase планируется без публикации исходного кода.

### [Dino Game](https://github.com/Richbanker/dino-game)

Командный fullstack-проект с Canvas-игрой, SSR, форумом, PostgreSQL, Service Worker и Docker. Моя роль: тимлид, архитектура, командная координация, CI/CD и инфраструктура.

### [Stellar Burger](https://github.com/Richbanker/react-burger)

Конструктор заказов на React и TypeScript с Redux Toolkit, React DnD, маршрутизацией и Playwright smoke-тестом.

### [TypeScript Messenger](https://github.com/Richbanker/middle.messenger.praktikum.yandex)

Клиентский прототип мессенджера без React: собственные компоненты, EventBus, History API, валидация форм и XHR-транспорт.

### [PulseBoard](https://github.com/Richbanker/pulseboard)

Dashboard с имитацией потока данных через mock WebSocket, состоянием на Zustand и графиками Recharts.

### [Good Deeds Calendar](https://github.com/Richbanker/good-deeds-calendar)

Telegram Mini App на React и TypeScript с Zustand, LocalStorage и адаптивным интерфейсом.
